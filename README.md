# 리아 이유식 식단표

프랑스식 초기 이유식(D+160~D+187) 식단표 웹앱입니다. 외부 라이브러리 없이 단일 `index.html`로 동작하며,
iOS 사파리에서 "홈 화면에 추가"하면 앱처럼 열립니다.

- 날짜(주차)별 식단과 재료 g수 확인·수정, 변경 시 영양(열량·탄단지·지방산) 실시간 재계산
- 새 재료 달력: 월별 미니 달력에 재료별 첫 시작일과 관찰 3일을 표시 (재료를 바꾸면 바로 반영)
- 먹임 완료·선호도·변 상태·메모 기록 (기기 브라우저 localStorage에만 저장)
- "기록 백업"으로 JSON 내려받기, "복원"으로 되살리기
- 수치 기준: USDA FoodData Central / 농촌진흥청 국가표준식품성분표 / 식약처 공공데이터

배포: GitHub Pages (`main` 브랜치 루트).
